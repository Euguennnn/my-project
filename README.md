# my-project

Лабораторна робота №1 з курсу «Програмування скриптовими мовами»
(тема: «Основи DevOps та конфігурації локального середовища»).

## Структура

- `src/my-project/lib.py` — модуль з функціями (`factorial`, `is_palindrome`, `count_vowels`, `fibonacci`)
- `src/my-project/main.py` — точка входу, імпортує та викликає функції з `lib.py`
- `src/my-project/test.py` — прості перевірки функцій (доданий у feature-гілці)

## Запуск

```bash
uv run python src/my-project/main.py
```
